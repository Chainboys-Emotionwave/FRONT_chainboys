# EmotionWave Village - 전체 src 폴더 구조 및 파일 정보 정리

## 📁 src/ 폴더 전체 구조

### 🎯 메인 애플리케이션 파일들
- **App.js** (150줄) - React Router 설정 및 전체 앱 구조
- **index.js** - React 앱 진입점
- **App.css** - 전역 스타일
- **index.css** - 기본 스타일

### 📄 src/pages/ 폴더 내 파일들 설명

### 1. Admin.js (535줄)
**관리자 페이지**
- 관리자 권한 확인 및 대시보드
- 4개 탭으로 구성: 대시보드, 보상 풀 관리, 보상 분배, 콘텐츠 관리
- 주요 기능:
  - 플랫폼 현황 (DAU, 신규 사용자, 콘텐츠, 응원 수)
  - 보상 풀 예치 및 관리
  - 주간 보상 분배 실행
  - 사용자 신고 및 콘텐츠 관리
- 데모 데이터로 관리자 통계, 보상 분배 내역, 신고 목록 포함

### 2. Collection.js (653줄)
**내 집 페이지 (개인 컬렉션)**
- 사용자 프로필 및 개인 공간 관리
- 방 인테리어 형태로 가구 클릭 시 정보 표시
- 주요 기능:
  - 프로필 정보 (닉네임, 지갑 주소, 총 보상/응원/뱃지)
  - 보상 내역 확인
  - 내 콘텐츠 관리
  - 뱃지 컬렉션
  - 마을 가이드 및 통계
- 이모지 마스터 데이터 (100개)와 색상 마스터 데이터 (20개) 포함

### 3. ContentDetail.js (304줄)
**콘텐츠 상세 페이지**
- 개별 콘텐츠의 상세 정보 표시
- 주요 기능:
  - 영상 플레이어 (YouTube 임베드)
  - 콘텐츠 정보 (제목, 창작자, 카테고리, 설명, 태그)
  - 응원하기 기능 (응원권 시스템)
  - 챌린지 참여 정보
  - 창작자의 다른 콘텐츠 추천
- 지갑 연결 상태에 따른 응원 기능 제어

### 4. Festival.js (576줄)
**마을 축제 페이지**
- 진행 중인 축제 목록 및 참여 콘텐츠 표시
- 주요 기능:
  - 축제 목록 (빌보드 챌린지, 댄스 챌린지 등)
  - 축제별 참여 콘텐츠 목록
  - 축제 정보 (참여자 수, 상금, 기간)
  - 콘텐츠별 응원 수 및 카테고리 표시
- 축제 선택 시 해당 축제의 참여 콘텐츠들을 그리드 형태로 표시

### 5. Home.js (602줄)
**홈페이지 (마을 지도)**
- 마을 건물들을 클릭하여 각 기능에 접근
- 주요 기능:
  - VillageMap 컴포넌트로 마을 지도 표시
  - 건물별 모달 (마을회관, 음악실, 축제장, 주민센터, 명예의 훈장, 공동 금고, 아트 갤러리, 이벤트 홀)
  - 각 건물별 특화된 콘텐츠 및 기능 제공
  - BuildingModal 컴포넌트로 건물 정보 표시

### 6. HomeOld.js (1477줄)
**홈페이지 (구 버전)**
- 더 상세한 홈페이지 구현
- 주요 기능:
  - 온라인 주민 현황
  - 명예의 훈장 시스템
  - 마을 건물들 (음악실, 축제장, 시청, 내 집)
  - 아티스트별 전용 마을 (음악, 아트, 댄스, 코미디)
  - 마을 활동 (일일 퀘스트, 마을 이벤트)
  - 마을 소식
  - 실시간 이벤트 알림
  - 마을 현황 통계
  - 인기 작품 목록
- 시간대별 테마 변경 기능 포함

### 7. ProfileEdit.js (471줄)
**프로필 편집 페이지**
- 사용자 프로필 설정 및 변경
- 주요 기능:
  - 닉네임 변경 (20자 제한)
  - 프로필 이미지 선택 (100개 이모지 옵션)
  - 프로필 배경색 선택 (20개 그라데이션 옵션)
  - 실시간 프로필 미리보기
  - 프로필 변경 가이드
- 카테고리별 이모지 분류 (음악, 아트, 댄스, 별/반짝임, 동물/자연)

### 8. Ranking.js (476줄)
**랭킹 페이지**
- 마을 주민들의 랭킹 시스템
- 주요 기능:
  - 주간 랭킹 / 명예의 전당 탭
  - 카테고리별 필터링
  - 개인 순위 정보 (로그인 시)
  - 창작자별 상세 정보 (응원 수, 콘텐츠 수, 성장률, 뱃지)
  - 응원 트렌드 차트
  - 순위별 배지 시스템 (1-3위 특별 표시)

### 9. Search.js (503줄)
**검색 페이지**
- 창작자 및 콘텐츠 검색 기능
- 주요 기능:
  - 실시간 검색 (URL 파라미터 지원)
  - 창작자 검색 결과
  - 콘텐츠 검색 결과
  - 검색 결과 요약 (창작자 수, 콘텐츠 수)
  - 검색 결과 없을 때 안내 메시지
- 창작자 15명, 콘텐츠 20개의 데모 데이터 포함

### 10. Upload.js (397줄)
**콘텐츠 업로드 페이지**
- 새로운 콘텐츠 등록
- 주요 기능:
  - 제목, 영상 링크, 카테고리, 설명 입력
  - YouTube/TikTok 링크 지원
  - 마을 축제 참여 선택
  - 배지 메타데이터 미리보기
  - 등록 가이드 제공
- API 연동 (localhost:8000/api/contents)
- 지갑 연결 상태 확인

### 11. VillageGuide.js (352줄)
**마을 가이드 페이지**
- 마을 이용 가이드 및 규칙 안내
- 주요 기능:
  - 마을 규칙 (서로 존중, 창작물 보호, 긍정적 에너지)
  - 마을 시스템 가이드 (음악 창작, 마을 축제, 명예의 훈장, 공동 금고)
  - 아티스트별 전용 마을 소개
  - 마을 레벨업 시스템 (새싹→성장→성숙→명예 시민)
- 각 기능별 링크 버튼 제공

### 12. Welcome.js (237줄)
**웰컴 페이지**
- 사이트 첫 진입 시 환영 페이지
- 주요 기능:
  - 애니메이션 효과가 있는 환영 화면
  - 배경 요소들 (구름, 나무, 꽃) 애니메이션
  - 마을 입장 버튼
  - 반응형 디자인
- CSS 애니메이션 (float, bounce) 포함

**보상 풀 패널 컴포넌트**

### 6. RankingList.tsx (212줄)
**랭킹 리스트 컴포넌트 (TypeScript)**

- 크리에이터 랭킹 표시
- 기간별/콘텐츠 타입별 필터링
- 응원수, 보상, 뱃지, 성장률 표시

- 스크롤 가능한 내용 영역
- 배경 클릭으로 닫기

## 📋 전체 구조 요약

### 🎯 주요 기능별 분류
1. **인증 시스템**: AuthContext, authService, WalletConnect
2. **UI 컴포넌트**: Navigation, Footer, VillageMap, BuildingModal
3. **블록체인 연동**: contracts.js, RewardPoolPanel
4. **데이터 표시**: RankingList (TypeScript)
5. **페이지 라우팅**: App.js (React Router)

### 🔗 의존성 관계
- **App.js** → 모든 페이지 컴포넌트 + Navigation + Footer
- **AuthContext** → authService + WalletConnect
- **RewardPoolPanel** → contracts.js
- **VillageMap** → BuildingModal
- **모든 페이지** → AuthContext (useAuth 훅)

### 📊 기술 스택
- **Frontend**: React, React Router, Material-UI
- **Blockchain**: Ethers.js, MetaMask
- **Styling**: CSS-in-JS, 반응형 디자인
- **Language**: JavaScript (ES6+), TypeScript (RankingList)
- **State Management**: React Context API
