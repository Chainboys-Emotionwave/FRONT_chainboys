# 상세 화면 설계 (Screens Spec)

## 공통
- 네비게이션: 홈, 보관함, 랭킹, (관리자) 보상 풀
- 상태: 미로그인(지갑 미연결), 로그인(지갑 연결)

## 메인(홈)
- 섹션: 인기 콘텐츠 그리드(썸네일/제목/가격/구매 버튼)
- CTA: 콘텐츠 업로드 버튼

## 콘텐츠 등록
- 필드: 유튜브 링크, 제목, 설명
- 행동: 등록하기(POST /api/contents)
- 상태: 유효성 실패(에러 메시지), 제출 중(로딩), 성공(상세로 이동)

## 콘텐츠 상세
- 정보: 제목, 창작자 지갑, 등록일, 설명, 플레이어, 총 응원 수
- 상태별 UI
  - 미로그인: '지갑 연결' 버튼
  - 로그인·미응원: '응원하기' 버튼
  - 로그인·응원함: '응원 완료'(비활성)
- 알림
  - 응원 클릭: "소량 가스비가 발생합니다" 확인 팝업
  - 성공: "응원이 기록되었습니다" 토스트

## 내 보관함
- 리스트: 보유 NFT(썸네일/제목/가격/거래 이력 일부)
- 수익: 누적 로열티, 출금 버튼

## 랭킹
- 뷰: 주간/월간 탭, 정렬(거래량/좋아요)
- 항목: 순위 배지, 제목, 지표(가격/거래/좋아요)

## 관리자(보상 풀)
- 입력: 총액, 기간, 분배 규칙
- 동작: 게시/수정, 정산 실행
- 기록: 정산 로그/이력
