# 주요 프로세스 (User Journeys & Flow)

## 프로세스 1: 창작자 첫 콘텐츠 등록
1) 지갑 연결/로그인
2) 등록 페이지 이동
3) 링크/제목/설명 입력 → 유효성 검사
4) 제출 → (백엔드) 검증/저장, (선택) IPFS 업로드 및 CID 저장
5) 성공 알림 → 상세 페이지 이동

## 프로세스 2: 팬 응원 → 랭킹 반영
1) 콘텐츠 상세 접속
2) '응원' 버튼 클릭 → 지갑 서명 요청
3) 트랜잭션 전송 → (스마트 계약) 이벤트 방출
4) (백엔드) 이벤트 수신/집계 → 랭킹 DB 업데이트
5) 프론트 UI '응원 완료' 표시 → 랭킹 페이지 반영

## 프로세스 3: 관리자 보상 정산
1) 보상 풀 설정(총액/기간/분배 규칙) 게시
2) 이벤트 기간 종료
3) 정산 실행 → 지급 트랜잭션 발생
4) 지급 이벤트 기록/로그 저장
5) 창작자 대시보드 수익 반영

## 프로세스 4: 보상 분배(온체인)
1) 관리자 또는 자동 트리거로 분배 실행 함수 호출
2) 입력 지표(응원/랭킹) 기반 분배 비율 계산(백엔드)
3) 컨트랙트에 배분 내역 전달 → 토큰 전송
4) 분배 이벤트 방출 → 백엔드 로그 저장 → UI 반영

## 프로세스 5: SBT 발급
1) 조건 충족 감지(예: 주간 1위, 최초 참가)
2) 발급 트리거(백엔드 또는 컨트랙트) 실행
3) SBT 민팅 → 지갑에 귀속(비양도)
4) 발급 이벤트 기록 → 마이페이지 배지 표시
