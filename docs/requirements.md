# 요구사항 분석

## 비전 (The Why)
K-POP 팬 창작자의 열정과 기여가 정당한 가치로 인정받는 생태계를 만든다. 저작권 이슈를 존중하면서, 창작 활동이 투명한 보상과 영구적 명예로 이어지도록 한다.

## 문제 정의와 핵심 해결책
- 문제: 2차 창작물(댄스 커버, 팬아트 등)은 원저작권으로 인해 직접 판매/수익화가 어렵고 기여가 휘발된다. 안무 저작권 인식도 낮다.
- 핵심 해결책(시상/Reward 모델): 거래형 NFT 마켓 대신, 보상 풀(Reward Pool)에 기반한 시상 모델을 채택한다. 온/오프체인 지표(응원·랭킹 등)에 따라 자동 분배하여 저작권 침해 없이 ‘활동/기여’에 보상한다.

## 사용자 역할 (User Roles)
- 팬 창작자: 콘텐츠 등록, 수익/보상 획득의 핵심 사용자
- 일반 팬: 콘텐츠 감상·응원·커뮤니티 참여, 랭킹에 영향
- 플랫폼 관리자: 보상 풀 이벤트 생성/운영, 정책 관리
- (가상) 아티스트/소속사: 보상 풀 재원 제공자(마케팅 예산, 자체 수익, 스폰서십/후원)

## 사용자 스토리 (User Stories)
- 팬 창작자: "나는 팬 창작자로서, 내가 만든 댄스 커버 영상 링크를 쉽게 등록하고 싶다. 보상 이벤트에 참여하기 위해."
- 일반 팬: "나는 일반 팬으로서, 내가 좋아하는 창작자에게 응원을 보내고 싶다. 그가 주간 랭킹에서 우승하도록 돕기 위해."
- 관리자: "나는 플랫폼 관리자로서, 이번 주 보상 풀의 총액과 분배 규칙을 설정하고 싶다. 새로운 이벤트를 시작하기 위해."

## 온체인 핵심 기능
- 보상 풀(Reward Pool): 외부 재원을 예치·보관하는 투명 금고. 온/오프체인 지표 기반 규칙으로 자동 분배. 모든 입·출금 내역 온체인 공개.
- 활동 증명 배지(SBT): 주간 랭킹 1위/최초 참가 등 조건 충족시 자동 발급되는 양도 불가 토큰으로 업적을 영구히 증명.

## 웹(오프체인) 지원 기능
- 팬 콘텐츠 허브: 유튜브/틱톡 링크 등록, 포트폴리오 관리
- 랭킹·응원 시스템: 팬 응원 → 실시간 집계 → 보상 분배 근거
- 마이페이지: 지갑 연결 후 보유 배지, 보상 내역 확인

## 성공 기준 (Acceptance Criteria) 요약
- 창작자는 링크/제목/설명 입력 후 등록을 완료할 수 있다.
- 팬은 로그인(지갑 연결) 상태에서 응원 트랜잭션을 보낼 수 있다.
- 관리자는 보상 풀 금액/규칙을 설정·수정·게시할 수 있다.
