# 아키텍처 및 기술 스택 (임시)

## 기술 스택
- 프론트엔드: React(현 구조), 차후 Next.js 전환 고려, Ethers.js(지갑 연동)
- 백엔드: Node.js(Express), DB(랭킹 집계/사용자/콘텐츠 관리)
- 블록체인: Solidity(보상 풀, SBT), Ethereum Sepolia Testnet
- 스토리지: IPFS(Pinata) 메타데이터 저장

## 구성요소
- Web App(프론트): 라우팅, 업로드/상세/랭킹/보관함/관리자 화면
- API 서버: 등록/집계/설정/로그, 온체인 이벤트 리스닝
- 컨트랙트: RewardPool, SBT(비양도 토큰)
- 작업자(Worker): 랭킹 집계 배치, 분배 준비, 알림

## 데이터 흐름(상위)
1) 업로드: 프론트 → API(검증/저장) → (선택) IPFS → DB 기록
2) 응원: 프론트 → 지갑 트랜잭션 → 컨트랙트 이벤트 → 백엔드 수신/집계
3) 분배: 백엔드 지표 계산 → 컨트랙트 분배 호출 → 이벤트/로그 → UI 반영
4) SBT: 조건 판별 → 컨트랙트 민팅 → 이벤트 → 마이페이지 표기
