# 기능 개발 정의 (WBS)

## 스토리 → 기능 분해 예시
- 스토리: 팬 창작자가 영상 링크를 등록하고 싶다
- 기능: 팬 콘텐츠 등록 기능

### 프론트엔드
- 콘텐츠 등록 페이지 UI (입력창, 버튼, 유효성 검사)
- 입력 필드: 유튜브 링크, 제목, 설명
- 등록 버튼 클릭 → 백엔드 API 호출 로직

### 백엔드
- POST /api/contents: 콘텐츠 정보 저장 API
- DB 스키마 설계: contents(id, creatorWallet, title, description, link, created_at, cid?)
- IPFS 업로드 연동 후 CID 저장(선택)

### 스마트 계약
- (등록 시점 직접 연동 없음) 추후 거래/응원/보상 정산과 연동

## 추가 기능 WBS 요약
- 응원(Like/Support)
  - 프론트: 응원 버튼/상태, 지갑 서명/오류 처리
  - 백엔드: 이벤트 수집/중복 방지/지표 집계 API
  - 컨트랙트: 응원 기록 이벤트 방출, 포인트 적립 로직(선택)
- 랭킹
  - 백엔드: 집계 배치, 캐시, 조회 API(정렬/필터/페이지)
  - 프론트: 랭킹 UI, 정렬/필터, 상세 이동
- 보상 풀(Reward Pool)
  - 컨트랙트: 예치, 분배 규칙, 분배 실행 함수, 이벤트
  - 백엔드: 분배 입력 데이터 산출(지표 계산), 실행 오케스트레이션
  - 프론트: 관리자 설정 UI(총액/기간/규칙), 실행/로그 확인
- 활동 증명 배지(SBT)
  - 컨트랙트: SBT 발급/메타데이터, 비양도성 제약
  - 백엔드: 발급 조건 판정, 발급 트리거
  - 프론트: 마이페이지 배지 목록/상세
